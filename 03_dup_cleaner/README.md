# 重複檔案與大檔案清理助手

Windows 桌面工具，找出電腦中佔用空間的大檔案，以及內容完全相同的重複檔案，
並把不要的重複檔案移到資源回收筒。

- **第一階段**：檔案統計、最大的前 20 個檔案
- **第二階段**：用 MD5 找出內容完全相同的重複檔案
- **第三階段**：勾選要清理的檔案，移到 Windows 資源回收筒

## 快速開始

```bash
python main.py
```

不需要 `pip install`，只用到 Python 標準函式庫。

## 使用步驟

1. 按「選擇資料夾」，挑一個要掃描的位置。
2. 按「開始掃描」。
3. 在「重複檔案」區域點擊方塊勾選要清理的檔案（**不會自動勾選**）。
4. 按「清理選取檔案」，確認後檔案會移到資源回收筒。

### 三種點擊方式

| 點擊位置 | 作用 |
| --- | --- |
| 檔案列的「選取」欄 | 勾選／取消勾選**單一檔案** |
| 群組列的「全選」 | 勾選**整組**重複檔案 |
| 群組列的「取消全選」 | 取消**整組** |

## 重複檔案是怎麼判斷的

為了避免做白工，分兩階段比對：

```
所有檔案
   ↓
依「檔案大小」分組
   ↓
大小只出現一次 → 一定不重複，排除
   ↓
大小出現兩次以上 → 算 MD5（hashlib，一次讀 1 MB）
   ↓
MD5 相同 → 判定為內容完全相同
```

**重點：大小不同就絕不可能重複**，所以只有大小相同的檔案才會被讀取內容。

MD5 使用 `usedforsecurity=False`，因為這裡只用來比對檔案內容，不涉及安全性，
在啟用 FIPS 規範的 Windows 上也能運作。

## 「可釋放空間」與「預計釋放空間」的差別

| 名稱 | 意義 |
| --- | --- |
| **可釋放容量** | 所有重複群組加起來，理論上最多能清掉多少（每組保留一個） |
| **預計釋放空間** | 只算你**勾選**的那些檔案，實際會清掉多少 |

兩者會隨著勾選即時更新。

## 清理檔案是安全的嗎？

**會移到 Windows 資源回收筒，不是永久刪除。**

`recycle.py` 直接呼叫 Windows 系統 API `SHFileOperationW`，並且一定要帶
`FOF_ALLOWUNDO` 這個選項，檔案才會進資源回收筒，隨時可以還原。
不是自己建立一個假的資料夾來假裝刪除。

清理前一定會跳出確認視窗，寫清楚要清理幾個檔案、可以釋放多少空間。
沒有勾選任何檔案時按清理，只會提示你，不會動任何檔案。

## 錯誤處理

| 情況 | 結果 |
| --- | --- |
| 沒勾選任何檔案 | 提示「請先勾選要清理的檔案」，不執行任何動作 |
| 在確認視窗按「否」 | 取消清理，勾選狀態保留 |
| 檔案已不存在 | 該檔案列入失敗清單，其他檔案照常處理 |
| 檔案被鎖住／正在使用中 | 該檔案列入失敗清單 |
| 沒有權限 | 該檔案列入失敗清單 |
| 部分失敗 | 顯示「成功 N 個，失敗 M 個」，並列出是哪幾個檔案、原因 |

清理後畫面會自動重算：檔案總數、總容量、最大的前 20 個檔案、
重複群組數、重複檔案總數、可釋放容量。
某個群組如果清理後只剩一個檔案，就不再顯示為重複群組。

## 設計說明

**Tkinter 只能由主執行緒操作。**
掃描和清理都放在背景執行緒（`threading`），背景執行緒只負責存結果，
由主執行緒用 `after()` 定期輪詢並更新畫面。
背景執行緒絕對不能直接呼叫 Tkinter，否則會出現
`RuntimeError: main thread is not in main loop`。

**記憶體用量**
掃描結果會保留所有檔案的「路徑 + 大小」，
這樣清理完之後才能正確重算「最大的前 20 個」
（不能只從舊的前 20 名裡過濾，因為原本排在第 21 名的檔案可能該補進來）。
